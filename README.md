# Español A2 → B2: тренажёр на 60 дней

Интерактивный тренажёр испанского для тех, кто уже на A2 и хочет дойти до B2 за два месяца. Один урок в день, 10–20 минут, плюс карточки на 3000 частотных слов с повторением на 1-й, 3-й, 7-й и 21-й день. Работает без интернета, прогресс хранится на устройстве и переносится файлом или кодом.

## Как запустить

Вариант 1, без установки: скачать репозиторий и открыть `index.html` в браузере. Всё работает с диска, без сервера и без сборки.

Вариант 2, как приложение на телефоне: опубликовать на GitHub Pages (в настройках репозитория Settings → Pages → Source: GitHub Actions; workflow уже лежит в `.github/workflows/pages.yml`). После первого открытия по ссылке приложение кэшируется service worker'ом и открывается оффлайн. На телефоне выбери «Добавить на главный экран».

Вариант 3, локальный сервер для разработки:

```
npm start
```

и открыть http://localhost:8080.

## Что внутри

Курс из 10 модулей по 6 дней: пять уроков с новой темой и шестой день с проверкой модуля. Всего 60 дней, 400 слов, около 700 упражнений плюс генерируемые дриллы на спряжение.

| Модуль | Дни | Тема |
|---|---|---|
| 1 | 1–6 | Ser/estar, presente, indefinido, imperfecto |
| 2 | 7–12 | Perfecto, pluscuamperfecto, перифразы, местоимения-дополнения |
| 3 | 13–18 | Futuro, condicional, реальные условия |
| 4 | 19–24 | Subjuntivo: формы, желания, эмоции, мнение, цель |
| 5 | 25–30 | Subjuntivo: время, относительные, уступка, вероятность; imperativo |
| 6 | 31–36 | Косвенная речь, imperfecto de subjuntivo, условия II и III типа |
| 7 | 37–42 | Пассив, ser/estar продвинутый, por/para, коннекторы |
| 8 | 43–48 | Перифразы, глаголы изменения, se, gustar-глаголы, предлоги |
| 9 | 49–54 | Аргументация, письма, жалобы, идиомы, описание данных |
| 10 | 55–60 | Сводные повторения, лексика B2, работа с текстом, экзамен |

Каждый урок: повторение слов по интервальному методу, грамматика с объяснением на русском, восемь новых слов с озвучкой, упражнения шести типов (выбор, ввод формы, сборка предложения, перевод, соединение пар, диктант) и итог с баллом.

После обязательной части каждого урока предлагаются необязательные блоки, любой можно пропустить: пять форм спряжения по теме дня, три задания из прошлых тем (чаще из тех, где было больше ошибок), мини-письмо на 2–3 предложения с образцом для самопроверки, произношение трёх фраз с озвучкой и, если браузер умеет распознавать речь, проверкой микрофоном, раунд «Найди пары» на словах дня. Результат урока фиксируется до дополнительных блоков и от них не зависит.

Прогресс: серия дней, очки, ориентировочный уровень, отставание или опережение плана, карта активности, список ошибок для повторной проработки, раздел «Слабые темы» с прорешиванием, словарь с состоянием каждого слова.

## План недели

На главной и в разделе «План недели» на каждый день выбирается одна тренировка: урок курса, карточки, слова курса, работа над ошибками, спряжения, мини-письмо, «Найди пары» или день отдыха. Без выбора день считается уроком. Есть быстрые шаблоны на неделю (каждый день урок; будни урок, выходные отдых и другие), можно планировать следующие недели. Главная показывает тренировку на сегодня с кнопкой запуска. День отдыха не прерывает серию и сдвигает расчётный день и дату финиша двухмесячного плана.

## Карточки: 3000 частотных слов

Отдельный модуль по принципу Anki. Словарь из 3000 самых употребительных слов и выражений с переводом, коротким контекстным предложением и его переводом лежит в `js/data/words/w01.js` … `w10.js` в порядке убывания частотности (порядок приблизительный, по частотным словарям испанского, а не по точному корпусному счёту).

График повторений фиксированный: слово, выученное сегодня, возвращается на 1-й, 3-й, 7-й и 21-й день. Даты считаются от дня изучения, а не от последнего повтора, поэтому пропуск не сдвигает график вперёд. После 21-го дня слово считается усвоенным и закрепляется ещё через 2 и 6 месяцев. Ответ «Не помню» возвращает карточку в начало графика.

Просроченные карточки обязательно показываются в начале каждого урока курса (до 50 за урок, остальные ждут в разделе «Карточки»). Новые слова берутся в разделе «Карточки» или по кнопке в итогах урока; лимит новых слов в день настраивается (по умолчанию 20). Первые сотни слов можно разом отметить известными, отдельное слово помечается кнопкой «Уже знаю».

Три режима показа: самооценка как в Anki (вспомнил, открыл ответ, нажал «Помню» или «Не помню»), выбор из четырёх вариантов и набор слова по переводу (активное воспроизведение, самый сильный способ запомнить). По умолчанию режимы чередуются, в настройках можно зафиксировать один. Горячие клавиши: пробел показывает ответ, 1 и 2 ставят оценку, 1–4 выбирают вариант. Слово с ошибкой в любом режиме показывается снова в той же сессии через несколько карточек и повторяется, пока ответ не будет верным; такие повторные показы не меняют график и не считаются в балл.

Тренажёр «Найди пары» на тех же 3000 словах: раунды по 12 плиток, источник слов на выбор (в изучении, выученные, любые, диапазон по частотности). Игра не меняет график повторений.

Состояние карточек входит в экспорт и импорт прогресса.

## Перенос прогресса

Раздел «Прогресс»: «Скачать файл» сохраняет JSON, «Скопировать код» кладёт в буфер текстовую строку. На другом устройстве выбери файл или вставь код и нажми «Импортировать». Можно объединить с текущим прогрессом или заменить его.

## Структура

```
index.html            оболочка
css/style.css         стили, светлая и тёмная тема
js/conjugation.js     генератор спряжений (правила + таблица неправильных)
js/store.js           прогресс в localStorage, SRS, экспорт/импорт
js/engine.js          типы упражнений, проверка ответов, озвучка
js/cards.js           карточки Anki: график 1–3–7–21, экран, сессии
js/data/words/        3000 частотных слов с примерами и переводами (по 300 в файле)
js/data/extras.js     темы мини-письма с образцами по дням
js/app.js             экраны и логика урока
js/data/curriculum.js модули курса
js/data/m01..m10.js   уроки: грамматика, слова, упражнения
sw.js                 service worker для оффлайна
test/                 тесты спряжений и валидация контента
```

## Тесты

```
npm test
```

Проверяются формы спряжений, серия с учётом дней отдыха, целостность уроков (все 60 дней на месте, индексы ответов корректны, число пропусков совпадает с числом ответов, глаголы в дриллах спрягаются), словарь карточек (ровно 3000 записей без дубликатов, четыре поля, без кириллицы в испанских полях) и график повторений карточек.

## Как добавить или поправить урок

Уроки лежат в `js/data/mXX.js`. Формат упражнений:

```js
{ t: 'mc',    q: 'вопрос с ___', o: ['вариант', ...], a: 0, e: 'пояснение' }
{ t: 'fill',  q: 'текст с ___ пропуском', a: ['ответ', 'вариант ответа'], hint: '...' }
{ t: 'fill',  q: 'два ___ пропуска ___', a: [['первый'], ['второй']] }
{ t: 'order', s: 'Предложение для сборки из слов.' }
{ t: 'tr',    q: 'Фраза по-русски', a: ['Перевод', 'Ещё вариант'] }
{ t: 'match', pairs: [['español', 'перевод'], ...] }
{ t: 'dict',  s: 'Испанская фраза для диктанта', ru: 'перевод' }
{ t: 'conj',  verbs: ['tener', 'hacer'], tenses: ['indef', 'subj'], n: 4 }
```

После правок запусти `npm test`.
